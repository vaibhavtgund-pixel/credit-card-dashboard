# credit-card-dashboard

• Built a 2-page Power BI dashboard analyzing credit card revenue and customer behavior across weekly transaction

A concise, two-page Power BI dashboard for analyzing weekly credit card transactions. The dashboard helps you explore revenue patterns and customer behavior using the included report images.

## What’s included
- Credit card transaction report (Credit card transaction report.png)
- Credit card customer report (credit card customer report.png)

## Purpose
This dashboard is designed to:
- Surface weekly revenue trends
- Help investigate customer behavior and segments
- Provide visual summaries that support quick analysis and decision-making

## Crux (for interview)
- Project: A focused, two-page Power BI report demonstrating end-to-end dashboard delivery.
- Goal: Analyze weekly transaction revenue and customer behavior to surface trends and potential actions.
- Key contributions to highlight: data preparation, metrics & KPIs definition, interactive visuals, and storytelling with insights.
- Talking points: how you chose KPIs, any DAX measures you built, performance/refresh considerations, and a specific insight you discovered (e.g., a revenue pattern or customer segment to target).

## How to view
- If you have the Power BI (.pbix) file, open it in Power BI Desktop or publish it to the Power BI Service.
- If you do not have the .pbix file, view the included PNG images in this repository to see the report pages.

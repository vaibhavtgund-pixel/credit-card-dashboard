Project Title: Credit Card Financial Dashboard
The project focuses on developing a comprehensive credit card financial dashboard to monitor real-time key performance indicators (KPIs) and weekly trends . The objective is to enable stakeholders to analyze credit card operations and support data-driven decision-making .

Key components and insights of the project include:
Data Integration: Connected Power BI to a SQL database to process transaction and customer datasets .
Advanced Analytics: Used DAX queries to calculate metrics like weekly revenue, transaction counts, and interest earned .
Performance Visualization: Created interactive reports comparing revenue, card categories, and demographic segments such as age, income, and job status .
Actionable Insights: Identified specific growth patterns and customer behavior, such as the highest default rates occurring within the self-employed category.
